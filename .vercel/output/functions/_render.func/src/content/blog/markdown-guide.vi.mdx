# Viết blog siêu đơn giản!

Bạn chỉ cần tạo file `.mdx` trong thư mục `src/content/blog/` là xong.

## Frontmatter

Phần trên cùng (giữa `---`) là metadata:

```yaml
---
title: "Tiêu đề bài viết"
description: "Mô tả ngắn"
pubDate: 2026-02-13
author: "Tên tác giả"
tags: ["tag1", "tag2"]
---
```

## Nội dung

Sau frontmatter, bạn viết Markdown bình thường:

- **Bold text**
- *Italic text*
- [Links](https://example.com)
- Images: `![Alt text](path/to/image.jpg)`
